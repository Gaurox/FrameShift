# FrameShift

🌐 [English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Français](README.fr.md) | **日本語** | [Bahasa Indonesia](README.id.md)

**Windows 向けの無料・オープンソースのメディア処理ツールです。動画、音声、画像、PDF を、シンプルな画面やエクスプローラーの右クリックメニューから処理できます。ローカル AI 機能も利用できます。**

**1.24.0** では、主に動画の視聴を想定した **「音量差を抑える」** 機能を追加しました。フランス語、日本語、インドネシア語が加わり、対応言語は **8 言語** になりました。CSV による翻訳への参加が簡単になり、更新時に選択した言語が、以前の設定が残っていてもアプリの画面に反映されるようになりました。[リリースノート](docs/RELEASE_NOTES_1.24.0.md)と[検証記録](docs/RELEASE_QUALIFICATION_1.24.0.md)をご覧ください。

ローカルの **1.24.0** インストーラーはプロジェクト所有者による確認が完了し、公開準備中です。以下の公開版ダウンロードは **1.23.0** です。1.23.0 では動画のカット画面に **Find Loop（ループを検索）** を追加し、従来の動画用右クリックメニューで一部の操作が表示されない問題を修正しました。

## ダウンロード

**[最新の公開版をダウンロード](https://github.com/Gaurox/FrameShift/releases/latest)**

公開版は **[1.23.0](https://github.com/Gaurox/FrameShift/releases/tag/v1.23.0)** です。このページの新機能と 8 言語への対応は、ローカルで確認済み・公開準備中の **1.24.0** の内容です。

対象は **Windows 10 / 11 の 64 ビット版**です。自己完結型インストーラーには .NET、FFmpeg、FFprobe が含まれているため、別途インストールする必要はありません。AI モデルは使用する機能に応じて別途取得します。

## 使い方

1. FrameShift を開き、動画、音声、画像、PDF をウィンドウにドラッグするか、追加ボタンを使います。
2. 処理するファイルと対応する操作を選びます。個別に選択しない場合は、キュー内の対応ファイルが対象になります。
3. 設定を調整し、利用できる場合はプレビューで確認します。
4. 処理を開始します。結果は元ファイルと同じフォルダーに一意の名前で保存され、元ファイルや既存の結果を上書きしません。

インストーラーでエクスプローラー連携を設定すると、右クリックメニューからも操作できます。メイン画面は Windows の右クリックメニューの選択数制限に依存せず、大きなバッチを追加できます。対応する形式とファイル数は操作ごとに異なります。

## 音量差を抑える

主に**映画などの動画を視聴する場面**を想定した機能です。小さな会話と、大きなアクション音や音楽の差を抑え、視聴中に何度も音量を調整する手間を減らします。音声ファイル単体にも利用でき、ミックス全体とすべての音声トラックを処理します。

- **弱**：ダイナミクスを比較的多く残す、穏やかな調整。
- **中**：標準設定。普段の視聴向け。
- **強 / ナイトモード**：小さな再生音量で聴くための、より強い調整。

処理はローカルで、**FFmpeg の 1 回の処理**で行います。再エンコードするのは音声だけで、**動画は再エンコードせずにコピー**します。チャンネル構成、字幕、チャプター、メタデータは保持されます。メイン画面とエクスプローラーの動画・音声メニューから利用でき、専用アイコンも用意されています。

対応形式や CLI オプションは、英語の[機能ガイド](docs/BALANCE_VOLUME.md)をご覧ください。

## 言語と翻訳への参加

**1.24.0** では、アプリ、字幕処理用ワーカー、インストーラー、エクスプローラーのメニュー項目が次の 8 言語に対応しています。

**English · 简体中文 · Español · Português (Brasil) · Русский · Français · 日本語 · Bahasa Indonesia**

フランス語、日本語、インドネシア語が今回の追加言語です。

インストール、更新、再インストールで選んだ言語は、Windows ユーザーごとに一度、**次回起動時に画面へ反映**されます。以前の言語設定が保存されていても新しい選択が適用され、ほかの設定は保持されます。

その後も設定画面のアプリ言語を変更し、FrameShift を再起動すれば別の言語を使えます。インストール済みのエクスプローラーメニューも更新されます。全ユーザー共通のメニューを変更するときは、Windows が管理者の許可を求める場合があります。この変更はすべてのアカウントに影響します。許可を取り消した場合やメニュー更新に失敗した場合は設定画面に通知され、アプリ用の言語設定は保存されます。

**翻訳への参加にプログラミングは不要です。** メンテナーから、英語の原文、文脈、翻訳を含む UTF-8 CSV を受け取ります。編集するのは **Translation 列だけ**です。変数や参照用の列を保持して保存し、ファイルを返してください。オフラインの保守ツールが、エクスポート、検証、変更点の確認、バックアップ付きのインポートを担当します。

英語の[翻訳者向けガイド](docs/TRANSLATING.md)、[用語集](docs/TRANSLATION_GLOSSARY.md)、[保守手順](docs/TRANSLATION_MAINTENANCE.md)を参照してください。検証とプロジェクトへの反映はメンテナーが行います。

## 主な機能

### 動画

| 操作 | 内容 |
| --- | --- |
| 動画を変換 | 形式やエンコード設定を変更します。 |
| 動画を圧縮 | 品質プリセットや対応する目標サイズを使って容量を減らします。 |
| 音量差を抑える | 動画を再エンコードせず、視聴時の会話と大きな音の差を抑えます。 |
| 音声を削除 | 音声のない動画コピーを作ります。 |
| 音声を抽出 | 最初の音声トラックを別ファイルに保存します。 |
| フレームを抽出 | 全フレーム、先頭、末尾、キーフレームを出力します。 |
| GIF を作成 | プレビューを確認しながら指定区間を GIF にします。 |
| 動画を結合 | クリップをタイムラインで並べて結合します。 |
| 字幕を追加 | 選択式の字幕トラックを追加するか、ビジュアルエディターで字幕を焼き込みます。 |
| 動画をカット / ループを検索 | 区間の選択、自然なループの検索、つなぎ目のプレビュー、往復ループを作成します。 |
| 動画を切り抜く | プレビュー、境界検出、ズームを使って画面を切り抜きます。 |
| 回転 / 反転 | 向きを修正し、鏡像にします。 |
| サイズを変更 | 動画の幅と高さを変更します。 |
| 再生速度を変更 | 動画を速くしたり遅くしたりします。 |
| 動画を補間 | 中間フレームを生成し、動きを滑らかにします。 |
| メディア情報 | ファイルの技術情報を確認します。 |

結合では、ストリームの条件が厳密に一致する場合に直接コピーします。ほかの対応する SDR 入力は H.264/AAC の MP4 に正規化し、余白で縦横比を保持し、音声がない場合は必要に応じて無音を追加します。この機能の初期版では HDR の混在や正規化に対応していません。

### 音声

形式変換、精密なカット、逆再生、ファイル容量の圧縮、音量差の調整、ピッチと速度の変更、ノイズ除去、ローカル AI による音源分離ができます。

### 画像と PDF

画像の変換と圧縮、複数サイズの `.ico` 作成、ビジュアル切り抜き、境界の自動検出、回転と反転、サイズ変更、画像を PDF ページに配置する編集機能があります。

### ローカル AI

| 操作 | モデル・機能 |
| --- | --- |
| 背景を削除 | BiRefNet の各モードと、ユーザーが手動で用意する任意の BRIA モード。 |
| オブジェクトを削除 | マスクを描画し、LaMa FP32 または LaMa 2025 で背景を補完します。 |
| 画像を拡大 | Real-ESRGAN x4plus、Anime 6B、Swin2SR。×2 / ×3 / ×4 または縦横比を保持した任意サイズ。 |
| 動画を拡大 | Real-ESRGAN General v3、AnimeVideo v3、x4plus Quality。対応する場合は FPS と音声を保持します。 |
| ノイズを除去 | DeepFilterNet3 で音声や動画の音声トラックを処理し、動画は再エンコードしません。 |
| 音源を分離 | HTDemucs でボーカル、ドラム、ベース、その他、インストゥルメンタルを出力します。 |
| 動画を補間 (RIFE) | 中間フレームを生成して動きを滑らかにし、スローモーションにも利用できます。 |
| 字幕を作成 | Whisper Base、Small、Large-v3 Turbo を独立したワーカープロセスで実行します。 |
| テキストを抽出 | PP-OCRv6 Small または Tiny で画像や PDF を処理し、TXT、JSON、検索可能 PDF を出力します。 |

字幕は SRT、ASS、単語単位の時刻を保持する FrameShift プロジェクトとして保存できます。OCR では PDF ページの選択、既存テキストの再利用、描画品質、段落のグループ化を設定できます。大きすぎるページはメモリ上限に収まる解像度で描画し、変更内容を通知します。

## ローカル AI とモデル

メディアは PC 上で処理され、アップロードされません。ダウンロード可能なモデルは初回使用時に取得し、整合性を検証します。モデルの準備後は対応する処理をオフラインで実行できます。モデルはインストーラーには含まれていません。

対応する機能は DirectML による GPU 処理を利用し、モデルに応じて CPU に切り替えます。画像拡大と動画拡大のモデルは別のフォルダーで管理します。速度と必要なリソースはモデルやハードウェアによって異なります。

設定では、明るいテーマ、暗いテーマ、システム設定に従うテーマを選べます。AI モデルのフォルダーを選択、開く、既定に戻すこともできます。モデルには通常の専用フォルダーを使ってください。ドライブのルート、システムフォルダー、インストール先は利用できません。

BRIA RMBG-2.0 のバランス・高品質モードは、[BRIA 公式モデルページ](https://huggingface.co/briaai/RMBG-2.0/tree/main)からユーザー自身がモデルを取得し、指定フォルダーに置く必要があります。FrameShift はこれらを同梱・自動ダウンロード・再配布しません。BRIA の非商用 CC BY-NC 4.0 条件を含め、[第三者コンポーネントとモデルの通知](THIRD_PARTY_NOTICES.md)を確認してください。

## 開発

**C#、.NET 8 LTS、WinForms、FFmpeg、FFprobe** を使用し、ローカル AI は ONNX Runtime DirectML を利用します。[global.json](global.json) で固定している SDK は **8.0.427** です。

Windows の PowerShell でリポジトリのルートから実行します。

```powershell
dotnet --version
dotnet restore .\src\FrameShift\FrameShift.csproj --locked-mode
dotnet restore .\src\FrameShift.SubtitlesWorker\FrameShift.SubtitlesWorker.csproj --locked-mode
dotnet restore .\tests\FrameShift.Tests\FrameShift.Tests.csproj --locked-mode
dotnet test .\tests\FrameShift.Tests\FrameShift.Tests.csproj --no-restore
dotnet run --project .\src\FrameShift\FrameShift.csproj
```

`dotnet --version` は `8.0.427` を表示する必要があります。これらは開発用コマンドで、配布用インストーラーは作りません。依存関係の復元には、設定済みのパッケージ配布元への接続が必要な場合があります。保存済みの言語設定とインストール言語がない場合は英語になります。設定で日本語を選び、再起動してください。

## インストーラーのビルド

Release ビルドでは ImageSharp 4 を使用するため、有効な非公開の `sixlabors.lic` が必要です。`SixLaborsLicenseFile` で指定し、[英語 README のライセンス手順](README.md#imagesharp-licence--maintainers-and-ai-agents)に従って有効期限を確認してください。キーの公開、ログへの出力、インストーラーへの同梱、検証の回避は行わないでください。利用者自身がこのビルド用ライセンスを用意する必要はありません。

現在のビルドは **Inno Setup 6.7.1** を使います。インストーラーの翻訳ファイルは、出典、翻訳者のクレジット、ライセンスとともに [`installer/Languages`](installer/Languages/README.md) に保存されています。

インストーラー作成の正式な入口は次のコマンドです。

```powershell
$env:SixLaborsLicenseFile = 'C:\private\sixlabors.lic'
.\build_installer.ps1
```

ライセンスのパスは実際の非公開パスに置き換えてください。必要な場合は `-IsccPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'` でコンパイラーを指定できます。

スクリプトは入力とバージョンを確認し、ロックされた依存関係を復元し、必須の Release テストを実行します。その後、自己完結型 `win-x64` を発行し、パッケージと翻訳を検証してインストーラーをコンパイルします。必須の検証が失敗した場合は原因を解決してください。GitHub への公開やインストーラーの実行は自動では行いません。
