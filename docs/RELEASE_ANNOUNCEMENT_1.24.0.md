## FrameShift 1.24.0

- **New “Balance volume” feature**  
  Primarily designed for watching videos, this feature reduces the differences between quiet dialogue and loud action scenes or music, so you do not have to keep adjusting the volume during a film. Three intensities are available, with Moderate selected by default. Processing runs in a single pass without re-encoding the video. The feature also works with standalone audio files.

- **Translation system overhaul and installation language fix**  
  Translations are now easier to contribute and maintain through CSV export and import. The language selected during installation or an update now also applies to the application windows, even when an older language preference was saved.

- **Three new languages**  
  Added **French**, **Japanese** and **Indonesian** across the application, installer and Windows context menus. FrameShift is now available in **eight languages**.
