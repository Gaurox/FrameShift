# Modal closing audit — 7 October 2026

The Remove Noise audio/video fix prompted a review of every `FormClosing` subscription and override under `src/FrameShift`. The review checked cancellation, nested calls to `Close()`, restoration of modal results and model availability before AI previews.

## Additional defects reproduced and corrected

| Window | Trigger and observed behavior | Correction |
| --- | --- | --- |
| Shared Download Model dialog | Closing during a download whose cancellation completes inline reenters the cancelled closing event. WinForms clears the modal result and the dialog remains open. | Post the final cancellation result and close with `BeginInvoke`, after cleanup and the original closing event. |
| Cut Video | A second native close while preview cleanup is pending bypasses the first close's wait. | Keep repeated requests cancelled until work finishes; post the final result. |
| Crop Image | A second native close during image-preview initialization bypasses the first close's wait. | Keep repeated requests cancelled until work finishes; post the final result. |

The downloader is shared by several AI features, so its correction applies wherever FrameShift uses `DownloadModelForm`. This finding concerns cancellation/closure of the download window.

## Coverage and results

The new `ModalClosingAuditTests` exercise real `ShowDialog()` message loops on STA threads. **53 cases pass:** 39 idle close cases (OK, Cancel and native close for 13 windows), 13 repeated-close cases with pending work, and one inline-download-cancellation case. Before the additional corrections, the downloader's inline case and the repeated-close cases for Cut Video and Crop Image failed; the 39 idle cases passed.

The 13 windows are Cut Audio, Create GIF, Crop Video, Join Videos, the subtitle burn editor, Remove Object, Image to PDF, Cut Video, Crop Image, Extract Text, Download Model, Remove Noise audio and Remove Noise video. Work is injected into the actual lifetime helpers or tracked tasks; these closure fixtures do not download models or run native inference.

The expanded Debug run also includes `UiEditorTests`, `UiD3Tests`, `OnnxFormLifetimeTests`, `CutAudioFormLifetimeTests`, `OcrUiTests` and `RemoveNoisePreflightTests`: **146 passed, 0 failed, 0 skipped**, in 1 minute 46 seconds. Existing editor tests additionally load real media through the bundled FFmpeg/FFprobe. `git diff --check` passes. Compilation emits the existing ImageSharp warnings because no licence file was supplied to this Debug invocation.

Other closing handlers either already defer final closure or synchronously reject invalid settings without attempting to close again. `ProgressForm` uses `Application.Run` and cancellation/close-mode flags, rather than a modal result. No additional instance of the same modal-closing defect was found in those handlers.

Remove Noise was the only settings picker found to expose an AI audio preview before its external model preflight. Remove Object checks/downloads its model before inference, and Extract Text performs preparation/model checks before accepting its settings.

These checks qualify the examined lifecycle behavior in the development build. Installed acceptance, real model download/inference cancellation and physical Windows DPI changes remain separate checks; no new installer was generated by this audit.
