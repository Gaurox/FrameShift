# Choix terminologiques français du pilote

Ces choix accompagnent la contribution ; ils ne valent pas validation indépendante
de la traduction. Le glossaire anglais fourni reste inchangé.

| Terme source | Choix français | Précision |
| --- | --- | --- |
| Balance volume | Équilibrer le volume | Différences de niveau dans le mixage entier. |
| Light / Moderate / Strong | Léger / Modéré / Fort | Intensités audio ; identifiants CLI inchangés. |
| Light / Dark | Clair / Sombre | Thème de l’application. |
| Night mode | Mode nuit | Équilibrage renforcé à faible volume. |
| Compress | Compresser | Réduire la taille du fichier. |
| Frame | Image | Image vidéo ; « trame » pour des échantillons audio entrelacés. |
| Frame rate / FPS | Fréquence d’images / FPS | FPS conservé dans les libellés courts et valeurs. |
| Track / stream | Piste / flux | Selon le contenu multimédia ; les suivis de recherche de boucle restent à confirmer. |
| Clip | Extrait | Élément ou segment vidéo de la chronologie. |
| Timeline | Chronologie | Assemblage des extraits vidéo. |
| Loop / junction | Boucle / raccord | Raccord entre la fin et le début. |
| Forward/backward / Ping-Pong | Aller-retour | Lecture à l’endroit puis à l’envers. |
| Candidate | Candidat | Proposition à prévisualiser, pas une garantie. |
| Proxy | Aperçu intermédiaire / en résolution réduite | Vérifier le détail sur l’export complet. |
| Cut / crop | Découper / recadrer | Temps / zone de l’image. |
| Resize / upscale | Redimensionner / agrandir | Agrandissement IA distingué dans les descriptions. |
| Pitch | Hauteur tonale | Distincte de la hauteur en pixels. |
| Remux / stream copy | Remultiplexer / copier les flux | Sans réencodage. |
| Burn subtitles | Incruster les sous-titres | Rendu dans les images vidéo. |
| Searchable PDF | PDF recherchable | PDF avec couche de texte. |
| Preset | Préréglage | Groupe de réglages. |
| Queue / batch | File d’attente / lot | Retirer un élément ne supprime pas la source. |
| Remove | Retirer / supprimer | Retirer de la file ; supprimer du contenu dans un nouveau résultat. |
| Stem | Piste séparée | Voix, batterie, basses, autres. |
| Matting | Détourage fin | Qualificatif de modèle ; identifiants inchangés. |
| Bit rate / sample rate | Débit binaire / fréquence d’échantillonnage | Deux grandeurs différentes. |
| FrameShift AI, FFmpeg, ONNX, DirectML, Whisper | Inchangés | Noms de produits et outils. |

Les formats numériques `{0:0.###}`, variables Inno, extensions et valeurs CLI
ne sont pas francisés. Les accélérateurs `&` sont conservés dans les libellés ;
les collisions et longueurs doivent encore être vérifiées visuellement.
